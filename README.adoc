= signer_app

CadenaBitcoin Signer is a mobile application for securely signing Discreet Log Contract (DLC) Bitcoin transactions.
It pairs with the DLCPlaza backend to receive, sign, and return Funding, Refund, and CET transactions.
The app supports both manual and automatic (user-approved) signing modes with built-in verification.
Designed for sovereignty and reliability, it runs on Android and iOS as a self-contained Bitcoin signer.

[NOTE]
====
Contributions are welcome from the open-source community to improve security, reliability, and multi-platform support.
Join us in building a fully sovereign Bitcoin signer that empowers peer-to-peer financial freedom.
====

== Requirements

* Flutter 3.35.3 (stable), with its bundled Dart SDK.
* Android Studio and Xcode for the platform builds.
* The pinned toolchain versions are listed in link:CLAUDE.md[CLAUDE.md], section 3.

== Running the project

. Clone the repository.
. Run `flutter pub get` in the repository root.
. Run `flutter pub get` also inside `flutter_plugin/flutter_plugin` before running the app.
. Start the application:
+
[source,bash]
----
flutter run --flavor staging --dart-define-from-file=config/build/staging.json
----
+
Every build needs an explicit environment and the matching flavor, `staging` or `production`. See link:docs/BUILD_CONFIGURATION.md[docs/BUILD_CONFIGURATION.md].
